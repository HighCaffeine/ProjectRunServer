## About The Project
**프로젝트 RUN**은 거대 보스를 처치하는 기존의 문법을 뒤집은 **'코옵 익스트랙션 런앤건'** 게임입니다. 
지루한 진입 과정을 생략하고, 퀘스트 목표물을 강탈한 직후부터 시작되는 압도적인 보스의 추격을 피해 3인이 협동하여 아슬아슬하게 탈출하는 텐션에 집중했습니다.

<br/>

## Key Features
* **시각화된 타임어택, 추격전**
  * 보스를 쓰러뜨리는 것이 아닙니다. 플레이어의 걷기 속도보다 빠르게 맵을 덮쳐오는 '보스 라인'을 피해 탈출구까지 멈추지 않고 달려야 합니다.
* **극한의 페널티와 릴레이 협동**
  * 목표물을 든 플레이어는 공격 불가, 이동속도 30% 감소, 스태미나 지속 감소 페널티를 받습니다.
  * 스태미나가 고갈되거나 회피기를 쓰면 오브젝트를 강제로 떨어뜨리므로, 다 같이 템포를 맞춰 목표물을 패스하고 길(기믹)을 여는 끈끈한 협동이 필수적입니다.
* **논스톱 런앤건 로그라이트**
  * 멈춰서 파밍할 여유는 없습니다. 도주로를 막는 적을 처치하면 장비가 오토 루팅되어 실시간으로 스탯이 오릅니다.

## How to Play

### Controls
| Action | Key | Action | Key |
| :--- | :--- | :--- | :--- |
| **이동** | `W` `A` `S` `D` | **들기 / 내려놓기** | `Mouse Right Click` |
| **공격 / 사용** | `Mouse Left Click` | **달리기** | `Shift` (스태미나 소모) |
| **회피기** | `Spacebar` | **아이템 교체** | 인벤토리 열고 `Right Click` |

### Core Rules
* **공용 목숨:** 파티 전체 목숨 3개 공유. 사망 시 목표 오브젝트와 먼 플레이어 근처에서 전진 리스폰.
* **승리 조건:** 목표 오브젝트를 가진 상태에서 최종 탈출구 도달.
* **패배 조건:** 3인 전원 사망 또는 '보스 라인'이 목표 오브젝트를 추월할 경우 즉시 패배.
